# Git changes

Leave changes uncommitted by default. Commit or push only when the user explicitly requests it for the current changes. Approval for an earlier change does not authorize committing or pushing later work.

# README screenshot

The project README must include a screenshot of the actual running web frontend's homepage, before any question is submitted. Keep the image in the repository and refresh it when visible frontend changes make it outdated.

Capture the real local application at the user's requested 90% browser zoom, with its normal fonts and layout fully loaded. Do not use mock API responses, injected conversations, altered CSS or font sizes, or blocked font requests. Inspect the image before adding it to the README. Do not change the webpage's styles just to change a screenshot's spacing. See `docs/development.md` for the capture requirements.
